Quiz Application

A simple quiz application built using Python and Tkinter.

Features

- Multiple-choice questions
- Displays questions with answer options
- Checks answers and displays results

Technologies Used

- Python
- Tkinter

How to Run

1. Install Python on your computer.
2. Download the "quiz.py" file.
3. Open a terminal in the file's folder.
4. Run "python quiz.py".
